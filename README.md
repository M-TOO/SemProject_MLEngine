## Open-Source Datasets for Parkinson's Risk Analysis

The following open-source datasets are relevant to Parkinson's disease risk analysis. 
The datasets include kinetic data and spiral drawing data.

### 1. Parkinson's Drawings Dataset

Kaggle - Parkinson's Drawings: https://www.kaggle.com/datasets/kmader/parkinsons-drawings

### 2. Overground Walking Kinematics and Kinetics Dataset

Figshare - Parkinson's Disease Walking Dataset: https://figshare.com/articles/dataset/A_dataset_of_overground_walking_full-body_kinematics_and_kinetics_in_individuals_with_Parkinson_s_disease/14896881?file=37907001

### 3. Parkinson Disease Spiral Drawings Dataset

UCI Machine Learning Repository - Parkinson Disease Spiral Drawings:
http://archive.ics.uci.edu/dataset/395/parkinson+disease+spiral+drawings+using+digitized+graphics+tablet

### 4. UCI Parkinson's Disease Classification Dataset:
https://archive.ics.uci.edu/dataset/470/parkinson+s+disease+classification
